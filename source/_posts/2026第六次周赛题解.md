# [A1](https://ac.nowcoder.com/acm/problem/17864)

## 题目描述

给定一个函数 $f(n)$，其定义如下：

$$f(n) = \begin{cases} n + 2017 & \text{if } n < 20180001 \\ f(f(n - 2018)) & \text{if } n \ge 20180001 \end{cases}$$

输入一个整数 $n(1 \le n \le 10^{18})$，输出 $f(n)$ 的值。
<!-- more -->
------

## 解题思路

我们直接令临界点 $T = 20180001$。考察紧贴着 $T$ 的上方区间，也就是 $n \in [20180001, 20182018]$ 这个范围。

通过代入推导可知 $f(n) = f(f(n-2018)) = f(n-1)$。这意味着函数值在这个区间内全部塌陷为常数 $f(T-1) = 20180000 + 2017 = 20182017$。 

也就是说，**对于第一个超界区间，结果恒为 $20182017$**。

我们受到上面的启发，考虑下一个区间 $n \in [20182019, 20184036]$。

此时 $n - 2018$ 会正好落在我们刚才推导的第一个区间 $[20180001, 20182018]$ 里。

我们已经知道，在这个区间内，$f(x)$ 的结果全都是 $20182017$。

所以内层 $f(n - 2018) = 20182017$。

代回外层：

$$f(n) = f(20182017)$$

如果不断推导下去，我们会发现,，当 $n \ge T$ 时， $f(n) = f(n-1)$ ，所有的数都会塌陷到为常数 $f(T-1) = 20180000 + 2017 = 20182017$。 

那么只要判断 $n$ 是否大于等于 $20180001$，就可以 $O(1)$ 出解了。

---

## 示例代码

```cpp
#include <iostream>

using namespace std;

int main() {
    long long n;
    cin >> n;
    if (n < 20180001) {
        cout << n + 2017 << '\n';
    } else {
        cout << 20182017 << '\n';
    }
    return 0;
}
```



# [A2](https://ac.nowcoder.com/acm/problem/276152)

## 题目描述

已知某个 $1 \sim n$ 的排列 $\{x_1, x_2, \dots, x_n\}$ 的**逆序数**为 $k$，请输出 $\{x_n, x_{n-1}, \dots, x_1\}$（即原序列翻转后）的逆序数。

**逆序数定义**：序列中满足 $i < j$ 且 $x_i > x_j$ 的数对 $(i, j)$ 的数量。

------

## 解题思路

长度为 $n$ 的排列中，任意两数 $(a, b)$ 的相对关系在原序列与翻转序列中必有且仅有一个是逆序。

- **结论：** 翻转后逆序数 = 总数对 - 原逆序数 = $\frac{n(n-1)}{2} - k$。
- **注意：** 计算总数对时需使用 `long long` 防止溢出。

------

## 示例代码

```cpp
#include <iostream>
using namespace std;

void solve() {
    long long n, k;
    if (cin >> n >> k) {
        long long total = n * (n - 1) / 2;
        cout << total - k << endl;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    solve();
    return 0;
}
```



# A3

## 题目描述

在一条笔直的公路上有 $n$ 个居民点，第 $i$ 个居民点的坐标为 $x_i$。

现在需要在公路上建立一个物资派发中心，为了使派发效率最高，请你选择一个合适的建址坐标，使得所有居民点到该派发中心的距离之和最小。请计算并输出这个最小的距离之和。

**输入描述：**

第一行包含一个正整数 $n$($1 \le n \le 10^5$)。第二行包含 $n$ 个整数 $x_1, x_2, \dots, x_n$($-10^9 \le x_i \le 10^9$)，分别表示每个居民点的坐标。相邻两个整数之间用空格隔开。

**输出描述：**

输出一个整数，表示所有居民点到派发中心的最小距离之和。

------

根据绝对值不等式性质，到 $n$ 个点距离之和最小的点即为这些坐标的**中位数**。将坐标排序后，取 $x_{\lfloor (n+1)/2 \rfloor}$ 作为选址即可。

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;

void solve() {
    int n; 
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }
    
    sort(a.begin() + 1, a.end());
    
    int m = (n + 1) / 2;
    int ans = 0;
    for (int i = 1; i <= n; ++i) {
        ans += abs(a[i] - a[m]);
    }
    cout << ans << '\n';
}

signed main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int _ = 1;
    while (_--) solve();
    return 0;
}
```



# [B1](https://ac.nowcoder.com/acm/problem/314601)

## 解题思路

给定长度为 $n$ 的数组，中位数定义为非降序排列后索引为 $\lfloor \frac{n-1}{2} \rfloor$ 的元素。设原中位数为 $M$。首先统计数组中三部分元素的个数：

- $L$：严格小于 $M$ 的元素个数。
- $X$：等于 $M$ 的元素个数。
- $R$：严格大于 $M$ 的元素个数。

若 $L=0$ 且 $R=0$（所有元素相同），则无法改变，输出 `-1`。求最小删除次数，即在满足“中位数偏移”的条件下，求解需要删除的元素个数 $d$ 的最小值。

**1. 使中位数变小（向左偏移）**

目标是让新中位数落在 $L$ 阵营，这意味着只能删除 $\ge M$ 的元素。由于题目中位数的索引公式 $\lfloor \frac{n-1}{2} \rfloor$ 在数组长度为偶数时天然偏向左侧，当左右两侧剩余数量为 $1:1$ 时，中位数会自动落在左侧。

因此，只需保证剩余的右侧（$\ge M$）元素总数不超过左侧即可。

假设最少删除 $d$ 个右侧元素，那么右侧剩余人数为 $(X + R - d)$。

列出目标条件不等式：$(X + R - d) \le L$

移项求解：$d \ge X + R - L$

因此，最少删除次数为 $d_1 = X + R - L$。（前提条件：$L > 0$）

**2. 使中位数变大（向右偏移）**

目标是让新中位数落在 $R$ 阵营，这意味着只能删除 $\le M$ 的元素。同样由于公式偏左，如果左右两侧数量 $1:1$，中位数仍会被规则按在左侧。为了强行将其拉到右侧，右侧剩余人数必须**严格大于**左侧， “**严格大于**”意味着至少要多 1 个。 

假设最少删除 $d$ 个左侧元素，那么左侧剩余人数为 $(L + X - d)$。

列出目标条件不等式：保留的左侧 $<$ 保留的右侧，即 $(L + X - d) \le R - 1$

移项求解：$d \ge L + X - R + 1$

因此，最少删除次数为 $d_2 = L + X - R + 1$。（前提条件：$R > 0$）

最终答案为 $\min(d_1, d_2)$ 。

------

## 示例代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    if (!(cin >> n)) return 0;

    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    sort(a.begin(), a.end());

    int m = (n - 1) / 2;
    int M = a[m];

    int L = 0, X = 0, R = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] < M) L++;
        else if (a[i] == M) X++;
        else R++;
    }

    if (L == 0 && R == 0) {
        cout << -1 << "\n";
        return 0;
    }

    int ans = 2e9; 
    
    if (L > 0) ans = min(ans, X + R - L);
    if (R > 0) ans = min(ans, L + X - R + 1);

    cout << ans << "\n";

    return 0;
}
```



# [B2](https://ac.nowcoder.com/acm/contest/116337/C)

 这是一道经典的**子序列计数问题**，可以通过动态规划的思想在 $O(n)$ 时间复杂度内解决。 

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
    
const int N=1e9+5;
    
void solve(){
    
    int n;
    cin >> n;
    string s;
    cin >> s;
    int q = 0, qc = 0, qcj = 0, qcjj = 0, qca = 0, qcay = 0;
    for(char c:s){
        if(c=='q'){
            q++;
        }
        else if(c=='c'){
            qc += q;
        }
        else if(c=='j'){
            // 先更新 qcjj，再更新 qcj，防止状态覆盖
            qcjj += qcj;
            qcj += qc;
        }
        else if(c=='a'){
            qca += qc;
        }
        else if(c=='y'){
            qcay += qca;
        }
    }

    cout << ((qcjj > qcay) ? "qcjj" : "qcay") << endl;
}
    
signed main(){
    
    ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);
    int _=1;
    cin>>_;
    while(_--)
    solve();
    return 0;
    
}
```

# C

## 题目描述

给定一个长度为 $n$ 的数组 `arr`，对于每个位置 $i$，我们需要找到一个位置 $j$，满足 `arr[i] <= arr[j]`，并且最大化绝对值距离 $|j - i|$。如果有多个满足最大距离的位置，输出最小的位置下标。

------

下面给出两种较为简单的方法。

### 解法一：预处理前缀/后缀最大值 + 二分查找

为了在 $O(\log N)$ 的时间内快速找到一左一右最远的候选点，我们可以利用“前缀最大值”和“后缀最大值”来强行制造**单调性**。

1. **寻找左侧最远候选点（最小的 $j \le i$）：**

   构建一个前缀最大值数组 `pmax`，其中 `pmax[k]` 表示前 $k$ 个元素的最大值。

   - `pmax` 数组随着下标增加是**单调不降**的。
   - 我们在区间 $[0, i]$ 内二分查找最小的 $j$，使得 `pmax[j] >= arr[i]`。一旦满足条件，记录答案并尝试继续向左逼近（`r = mid - 1`）。

2. **寻找右侧最远候选点（最大的 $j \ge i$）：**

   构建一个后缀最大值数组 `smax`，其中 `smax[k]` 表示从 $k$ 到末尾元素的最大值。

   - `smax` 数组随着下标增加是**单调不升**的。
   - 我们在区间 $[i, n-1]$ 内二分查找最大的 $j$，使得 `smax[j] >= arr[i]`。一旦满足条件，记录答案并尝试继续向右逼近（`l = mid + 1`）。

3. **得出结果：**

   计算出左边界 $L$ 的距离 $i - L$，和右边界 $R$ 的距离 $R - i$。如果距离相等，题目要求输出最小的位置，因此优先选择左边的下标 $L$。

**复杂度分析：**

预处理前后缀最大值需遍历两次数组，耗时 $O(N)$。对每个元素执行两次二分查找，单次 $O(\log N)$。总体时间复杂度为 $O(N \log N)$，空间复杂度为 $O(N)$。

## 示例代码

```cpp
#include<bits/stdc++.h>
#define int long long
using ll = long long;
using namespace std;
    
const int N = 1e5+5;
    
void solve(){
    int n; 
    if (!(cin >> n)) return;
    
    vector<int> a(n), pre(n), suf(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    // 预处理前缀最大值 (单调不降)
    pre[0] = a[0];
    for (int i = 1; i < n; ++i) {
        pre[i] = max(pre[i - 1], a[i]);
    }

    // 预处理后缀最大值 (单调不升)
    suf[n - 1] = a[n - 1]; 
    for (int i = n - 2; i >= 0; --i) {
        suf[i] = max(suf[i + 1], a[i]);
    }

    for (int i = 0; i < n; ++i) {
        int l = 0, r = i;
        int ans1 = i, ans2 = i;
        
        // 1. 找左侧最远点
        while (l <= r) {
            int mid = ((l + r) >> 1LL);
            if (pre[mid] >= a[i]) {
                ans1 = mid;
                r = mid - 1;
            }
            else {
                l = mid + 1;
            }
        }

        // 2. 找右侧最远点
        l = i, r = n - 1; 
        while (l <= r) {
            int mid = ((l + r) >> 1LL);
            if (suf[mid] >= a[i]) {
                ans2 = mid;
                l = mid + 1;
            }
            else {
                r = mid - 1;
            }
        }

        // 3. 比较距离，优先输出较小的下标
        if (i - ans1 >= ans2 - i) {
            cout << ans1 << (i == n - 1 ? "" : " ");
        }
        else {
            cout << ans2 << (i == n - 1 ? "" : " ");
        }
    }
    cout << "\n";
}
    
signed main(){
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int _ = 1;
    while (_--)
        solve();
    return 0;
}
```

### 解法二：map + set

使用 `std::map<int, vector<int>, greater<int>>` 将数组元素**按值从大到小**进行分组排序，并将同值的下标存在一起。

 一边遍历 `map`，一边把前面那些合法数的**下标**全扔进 `set` 里。 

既然 `set` 里的下标都合法，那离当前位置最远的点，绝对就是 `set` 里的**最小下标**（极左）或**最大下标**（极右），拿当前位置减一下，挑个最大的就行了。 



**复杂度分析：**

将 $N$ 个元素插入 `map` 和 `set` 各需要 $O(N \log N)$，查询红黑树极值是 $O(1)$ 的。总时间复杂度完美保持在 $O(N \log N)$，空间复杂度为 $O(N)$。

## 示例代码

```cpp
#include<bits/stdc++.h>
#define int long long
using ll = long long;
using namespace std;
    
const int N = 1e5+5;
    
void solve(){
    int n; 
    cin >> n;
    
    vector<int> a(n), ans(n);
    // map 按值从大到小排序，把值相同的下标全存进 vector 里
    map<int, vector<int>, greater<int>> mp;
    
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        mp[a[i]].push_back(i);
    }

    // 存放合法的下标集合
    set<int> s;

    for (auto& p : mp) {
        // 第一步：先把当前值对应的所有下标都扔进 set 里
        for (int idx : p.second) {
            s.insert(idx);
        }

        // 第二步：对于当前值的每一个下标，在 set 的两头找极值
        for (int idx : p.second) {
            int L = *s.begin();  // 极左端点
            int R = *s.rbegin(); // 极右端点
            
            // 比较距离，距离相等时优先选左边的（下标更小）
            if (idx - L >= R - idx) {
                ans[idx] = L;
            } else {
                ans[idx] = R;
            }
        }
    }

    for (int i = 0; i < n; ++i) {
        cout << ans[i] << " ";
    }
    cout << "\n";
}
    
signed main(){
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int _ = 1;
    // cin >> _;
    while (_--)
        solve();
    return 0;
}
```



# [D](https://ac.nowcoder.com/acm/contest/108303/C)

## 题目描述

给定一个长度为 $n$ 的排列 $P$，定义一个函数 $f(P)$：将排列中的元素逐个压入一个单调栈，每次压入前弹出栈顶所有大于当前元素的数，最后返回栈的长度。

题目要求计算所有可能的排列中，$(f(P))^3$ 的总和，并对 **998244353** 取模。



这道题最大的陷阱就是这个单调栈。实际上，当单调栈执行完毕后，留在栈里的元素有什么特征？

它们必须满足：**在它之后加入的所有元素，都比它大。**

换句话说，最后留在栈里的元素，正是这个排列的**从右向左的后缀最小值**！

比如排列 `[3, 1, 4, 2]`，从右往左的最小值分别是 `2` 和 `1`，所以最后栈的长度就是 **2**。

题目实质上要求的是：**长度为 $n$ 的所有排列中，“后缀最小值个数”的三次方之和。**



我们设 **$X$ 是随机排列中后缀最小值的个数**，也就是单调栈中剩下的数的个数。

------

### 解法一：期望 + 数学

要求总和，我们可以先求**期望**，最后再乘以排列总数 $n!$：

$$\text{Ans} = n! \times E[X^3]$$

**指示变量的独立性：**

如果从右往左看，第 $i$ 个位置的数要成为后缀最小值，它必须是后 $i$ 个数中最小的。在完全随机的排列中，这发生的概率是 $\frac{1}{i}$。

定义指示变量 $I_i$，若从右往左第 $i$ 个元素是后缀最小值则为 **1**，否则为 **0**。这 $n$ 个事件是相互独立的。所以 $X = \sum_{i=1}^n I_i$，且 $E[I_i] = \frac{1}{i}$。

( 在概率论中，对于这种只取 $0$ 和 $1$ 的变量，**它的数学期望就等于它取 $1$ 的概率**。 既然当最小值的概率是 $\frac{1}{i}$，那么它的期望 $E[I_i]$ 就是 $\frac{1}{i}$。 )

**代数展开：**

我们需要求 $E[X^3] = E[(\sum_{i=1}^n I_i)^3]$。利用代数展开：
$$
(\sum I_i)^3 = \sum I_i^3 + 3 \sum_{i \neq j} I_i^2 I_j + \sum_{i \neq j \neq k} I_i I_j I_k
$$
因为 $I_i$ 只能取 **0** 或 **1**，所以 $I_i^k = I_i$。并且因为它们相互独立，乘积的期望等于期望的乘积。

为了表达方便，我们定义：

$S_1 = \sum_{i=1}^n \frac{1}{i}$

$S_2 = \sum_{i=1}^n \frac{1}{i^2}$

$S_3 = \sum_{i=1}^n \frac{1}{i^3}$

将展开式代入 $S_k$，我们可以推导出：

- $\sum E[I_i] = S_1$
- $3 \sum_{i \neq j} E[I_i I_j] = 3(S_1^2 - S_2)$
- $\sum_{i \neq j \neq k} E[I_i I_j I_k] = S_1^3 - 3S_1S_2 + 2S_3$

把它们全部加起来，化简得到终极公式：
$$
E[X^3] = S_1^3 + 3S_1^2 - 3S_1S_2 - 3S_2 + 2S_3 + S_1
$$
预处理逆元和前缀和后，单次查询只需 $O(1)$。

---

### 示例代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const int MOD = 998244353;
const int MAXN = 500005;

ll inv[MAXN];
ll fact[MAXN];
ll S1[MAXN], S2[MAXN], S3[MAXN];

void solve() {
    int n;
    cin >> n;

    ll s1 = S1[n];
    ll s2 = S2[n];
    ll s3 = S3[n];

    ll s1_2 = s1 * s1 % MOD;
    ll s1_3 = s1_2 * s1 % MOD;

    // 根据数学推导的公式计算 E[X^3]
    ll E = s1_3;
    E = (E + 3 * s1_2) % MOD;
    E = (E - 3 * s1 * s2) % MOD;
    E = (E - 3 * s2) % MOD;
    E = (E + 2 * s3) % MOD;
    E = (E + s1) % MOD;

    // 防止 C++ 中的负数取模问题
    E = (E % MOD + MOD) % MOD;

    // 最终总和 = n! * E[X^3]
    ll ans = E * fact[n] % MOD;
    cout << ans << "\n";
}

int main() {

    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    // 线性求逆元
    inv[1] = 1;
    for (int i = 2; i < MAXN; i++) {
        inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD;
    }

    fact[0] = 1;
    S1[0] = S2[0] = S3[0] = 0;
    
    // 预处理阶乘与期望前缀和
    for (int i = 1; i < MAXN; i++) {
        fact[i] = fact[i - 1] * i % MOD;

        ll inv2 = inv[i] * inv[i] % MOD;
        ll inv3 = inv2 * inv[i] % MOD;

        S1[i] = (S1[i - 1] + inv[i]) % MOD;
        S2[i] = (S2[i - 1] + inv2) % MOD;
        S3[i] = (S3[i - 1] + inv3) % MOD;
    }
    
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```



如果你觉得这个解法太复杂，可以看看下面更简短，更巧妙的动态规划解法。

### 解法二：递推 DP

**状态定义：**

设 `dp[i][m]` 表示**长度为 $i$ 的所有排列中，后缀最小值个数的 $m$ 次方之和**。

+ `dp[i][0]` 就是 $X^0$ 的总和，也就是长度为 $i$ 的排列总数（$i!$）。

+ `dp[i][1]` 就是 $X^1$ 的总和（一次方之和）。

+ `dp[i][2]` 就是 $X^2$ 的总和（平方之和）。

+ `dp[i][3]` 就是 $X^3$ 的总和（立方之和）， `dp[n][3]`正是题目要求的最终答案！

  

而 `dp[n][0]` 实际上就是 $n!$。



**状态转移与组合思想：**

当我们想推导长度为 $i$ 的情况时，可以看作是在长度为 $i-1$ 的排列中插入一个新元素（由于是在已有排列上新加一个元素组成新排列，所以这个新元素一定比已有排列的最大值大1）。新加入的元素有 $i$ 个可能的位置：

1. **插在其他地方（$i-1$ 个位置）：** 不会增加后缀最小值的个数。此时个数依然是 $X$。
2. **插在最末尾（1个位置）：** 会产生一个新的后缀最小值。此时个数变成 $X + 1$。

根据这种轮换性质，可以得出递推式：
$$
(\text{长度为 } i \text{ 的 } X)^m \text{ 总和} = (i-1) \times ((\text{长度为 } i-1 \text{ 的 } X)^m \text{ 总和}) + ((\text{长度为 } i-1 \text{ 的 }X)+1)^m\text{ 总和}
$$


即：$$\text{dp}[i][m] = (i-1) \times \text{dp}[i-1][m] + \sum_{P} (X+1)^m$$

其中 $\sum_P$ 是对长度为 $i-1$ 的所有排列求和。

将 $(X+1)^m$ 利用**二项式定理**展开：

- **$m=1$ 时**：$(X+1)^1 = X + 1$

  所以：`dp[i][1]` = $(i-1) \times$ `dp[i-1][1]` + `dp[i-1][1]` + `dp[i-1][0]` 

  化简后：`dp[i][1] = dp[i-1][1] * i + dp[i-1][0]` 

- **$m=2$ 时**：$(X+1)^2 = X^2 + 2X + 1$

  所以：`dp[i][2]` = $(i-1) \times$ `dp[i-1][2]` + `dp[i-1][2]` + $2 \times$ `dp[i-1][1]` + `dp[i-1][0]`

  化简后：`dp[i][2] = dp[i-1][2] * i + 2 * dp[i-1][1] + dp[i-1][0]` 

- **$m=3$ 时**：$(X+1)^3 = X^3 + 3X^2 + 3X + 1$

  `dp[i][3] = dp[i-1][3] * i + 3 * dp[i-1][2] + 3 * dp[i-1][1] + dp[i-1][0]`

预处理后，单次查询只需 $O(1)$。

### 示例代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int M = 998244353;
ll dp[500005][4];
void solve(){
	int n; cin >> n;
	cout << dp[n][3] << endl;
}

int main()
{
    ios::sync_with_stdio(false); cin.tie(0); cout.tie(0);
    dp[0][0] = 1;
    for(int i = 1;i<=500000;i++){
		dp[i][0] = dp[i-1][0]*i%M;	
        //m = 0: 排列总数 (阶乘)
		dp[i][1] = (dp[i-1][1]*i%M + dp[i-1][0])%M;	
        //m = 1: 1次方之和
		dp[i][2] = (dp[i-1][2]*i%M + dp[i-1][1]*2%M + dp[i-1][0])%M; 
        // m = 2: 2次方之和
		dp[i][3] = (dp[i-1][3]*i%M + dp[i-1][2]*3%M + dp[i-1][1]*3%M + dp[i-1][0])%M; 
        // m = 3: 3次方之和
	}
    int _; cin >> _;
    while(_--){
        solve();
    }
    
    return 0;
}
```
