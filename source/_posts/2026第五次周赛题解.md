# WUSTACM周赛5题解

## [A1](https://atcoder.jp/contests/abc253/tasks/abc253_b)

### 标记间的距离 (Distance Between Tokens)

> 时间限制：1000ms | 内存限制：256MB    

<!--more-->

#### 题目描述

给定一个包含 $H$ 行 $W$ 列的网格，其中恰好有两个不同的方格内放置了标记（Token）。

网格的状态由 $H$ 个长度为 $W$ 的字符串 $S_1, \ldots, S_H$ 表示。

$S_{i, j} = \texttt{o}$ 表示在从上往下数第 $i$ 行、从左往右数第 $j$ 列的方格中存在一个标记；

$S_{i, j} = \texttt{-}$ 表示该方格为空。这里，$S_{i, j}$ 表示字符串 $S_i$ 的第 $j$ 个字符。  

考虑重复进行以下操作：将其中一个标记移动到与其相邻（上、下、左、右）的四个方格之一。严禁将标记移动到网格外部。

请问，最少需要多少次移动才能使该标记到达另一个标记所在的方格？

#### 数据范围约束

- $2 \le H, W \le 100$
- $H$ 和 $W$ 均为整数。  
- $S_i$ ($1 \le i \le H$) 是一个长度为 $W$ 的字符串，仅由 $\texttt{o}$ 和 $\texttt{-}$ 组成。  
- 全网格恰好存在两组不同的坐标 $(i, j)$ ($1 \le i \le H, 1 \le j \le W$) 满足 $S_{i, j} = \texttt{o}$。  

#### 输入格式

标准输入格式如下：

$H \quad W$

$S_1$

$\vdots$

$S_H$

#### 输出格式

输出最少移动次数。



---

记录两个点的坐标就行

~~~C++
using arr2 = array<int, 2>;

void solve() {
    int n, m;
    cin >> n >> m;
    arr2 s = {0, 0}, t = {0, 0};
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            char c; cin >> c;
            if (c == 'o') {
                if (s[0]) {
                    t = {i, j};
                }
                else s = {i, j};
            }
        }
    }
    cout << abs(s[0] - t[0]) + abs(s[1] - t[1]) << '\n';
}
~~~





## [A2](https://atcoder.jp/contests/abc228/tasks/abc228_c)

### 最终日 (Final Day)

> 时间限制：2000ms | 内存限制：1024MB

#### 题目描述

$N$ 名学生正在参加一场为期 $4$ 天的考试。

每天的测试满分均为 $300$ 分，四天总计满分为 $1200$ 分。

目前前三天的考试已结束，第四天的考试即将开始。第 $i$ 名学生（$1 \le i \le N$）在第 $j$ 天（$1 \le j \le 3$）获得了 $P_{i, j}$ 分。

请对于每名学生，判定他/她在第四天结束后，是否有**可能**排进前 $K$ 名（包括第 $K$ 名）。

在此，第四天结束后某位学生的排名定义为：四天总分**严格高于**该学生的总人数 $+ 1$。

#### 数据范围约束

- $1 \le K \le N \le 10^5$
- $0 \le P_{i,j} \le 300 \quad (1 \le i \le N, 1 \le j \le 3)$
- 输入中的所有值均为整数。

#### 输入格式

输入由标准输入给出，格式如下：

$N \quad K$

$P_{1,1} \quad P_{1,2} \quad P_{1,3}$

$\vdots$

$P_{N,1} \quad P_{N,2} \quad P_{N,3}$

#### 输出格式

输出共 $N$ 行。如果第 $i$ 名学生在第四天结束后有可能排在前 $K$ 名内，则第 $i$ 行（$1 \le i \le N$）输出 `Yes`；否则输出 `No`。

---



贪心的想，其他人都是0分，我得到300分，这时候我才最有可能排到前 $k$ 名

可以模拟的写，每次找出自己得到300分后的排名，看看是不是前 $k$ 名

要学会用`lower_bound`和`upper_bound`

~~~C++
using arr2 = array<int, 2>;

void solve() {
    int n, k; cin >> n >> k;
    vector<arr2>a(n + 5);
    vector<int>ans(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        int x = 0;
        for (int j = 1; j <= 3; j++) {
            cin >> x;
            a[i][0] += x;
        }
        a[i][1] = i;
    }
    sort(a.begin() + 1, a.begin() + 1 + n);
    for (int i = 1; i <= n; i++) {
        int pos = lower_bound(a.begin() + 1, a.begin() + 1 + n, arr2{a[i][0] + 301, -1}) - a.begin();
        if (n - pos + 2 <= k) ans[a[i][1]] = 1;
        else ans[a[i][1]] = 0;
    }
    for (int i = 1; i <= n; i++) {
        if (ans[i]) cout << "Yes" << '\n';
        else cout << "No" << '\n';
    }
}
~~~



事实上，我们只要找到第 $k$ 大的数就行了，看看得到300分后能不能大于它







## [A3](https://ac.nowcoder.com/acm/contest/82394/D)

## 题目描述                    

小红拿到了一个数组，她想知道有多少个长度为$k$的连续子数组是排列？

 定义排列为：1到$k$每个元素都恰好出现了1次。

## 输入描述:

第一行输入两个正整数$n,k$，代表小红拿到的数组大小和连续子数组的大小。
第二行输入$n$个正整数$a_i$，代表数组中的元素。
$1\leq k \leq n \leq 10^5$
$1\leq a_i \leq 10^5$

## 输出描述

一个整数，代表长度为k的连续子数组是排列的数量

----



注意到长度为 $k$ 的连续子数组只有 $n - k + 1$ 个，所以我们可以枚举出来这些区间

那我们怎么统计答案呢，如果每一个区间都暴力的统计那就是$O(n ^ 2)$ 的复杂度

事实上，我们在枚举这些区间的时候就可以统计答案，我们枚举每个区间的终点 $i$ 

那么当区间 $i - k + 1, i$ 向区间 $i - k + 2, i + 1$ 移动的时候，$i - k + 2, i$ 这个区间是重复的

也就是说当区间 $i - k + 1, i$ 向区间 $i - k + 2, i + 1$ 移动的时候，只是少了一个$a_{i - k + 1}$ ， 多了一个$a _ {i+1}$

我们只要更新这两个数对答案造成的影响就行了

我们先统计第一个区间$1, k$的答案，再开始移动就行了

~~~C++
void solve() {
    int n, k;
    cin >> n >> k;
    vector<int>a(n + 5, 0);
    map<int, int>mp;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (i <= k && a[i] <= k) {
            if (!mp[a[i]])sum++;
            mp[a[i]]++;
        }
    }
    int ans = 0;
    if (sum == k) ans = 1;
    for (int i = k + 1; i <= n; i++) {
        if (mp[a[i - k]] == 1) {
            sum--;
        }
        mp[a[i - k]]--;
        if (a[i] <= k) {
            if (!mp[a[i]]) {
                sum++;
            }
            mp[a[i]]++;
        }
        if (sum == k) ans++;
    }
    cout << ans << '\n';


}
~~~

$\hspace{15pt}$表、里两个世界各有 $n$ 个点，编号依次为 $1,2,\dots,n$。每个点都有一定数量的金币，表世界 $i$ 号点有 $a_i$ 枚金币，里世界 $i$ 号点有 $b_i$ 枚金币。
$\hspace{15pt}$Askalana初始位于表世界的 $1$ 号点，她拾起该点的金币。之后，她会向当前世界的下一个点移动一步（即，若她当前位于表世界的 $i$ 号点，则她会移动到表世界的 $i + 1$ 号点；若她当前位于里世界的 $i$ 号点，则她会移动到里世界的 $i + 1$ 号点），并拾起该点的金币。 
$\hspace{15pt}$但Askalana是大魔法师，如果她有不少于 $k$ 枚金币，则她可以选择消耗 $k$ 枚金币，让自己跃迁到对侧世界的 $i + 1$ 号点，并拾起该点的金币。跃迁结束后，如果不再次进行跃迁，她会在对侧世界继续行走下去。 
$\hspace{15pt}$在最优策略下，Askalana在走到 $n$ 号点时最多可以获得多少金币呢？

## 输入描述:

第一行输入两个正整数 $n, k \left(1 \leqq n \leqq 2 \times 10^5;\ 1 \leqq k \leqq 10^9\right)$ 代表点的数量、跃迁消耗的金币数量。

第三行输入 $n$ 个正整数 $b_1, b_2, \dots, b_n \left(1 \leqq b_i \leqq 10^9\right)$ 代表里世界每个点的金币数量。

## 输出描述:

输出一个正整数，代表Askalana在走到 n 号点时最多可以获得的金币数量。

假设表世界是 ![img](https://www.nowcoder.com/equation?tex=0&preview=true)，里世界是 ![img](https://www.nowcoder.com/equation?tex=1&preview=true)，令 ![img](https://www.nowcoder.com/equation?tex=f_%7Bik%7D&preview=true) 表示在 ![img](https://www.nowcoder.com/equation?tex=w&preview=true) 世界上抵达 ![img](https://www.nowcoder.com/equation?tex=i&preview=true) 号点时的最大金币，令 ![img](https://www.nowcoder.com/equation?tex=f_%7B1%2C%200%7D&preview=true) 初始为 ![img](https://www.nowcoder.com/equation?tex=a_1&preview=true)，![img](https://www.nowcoder.com/equation?tex=b_1&preview=true) 不可达，那么从 ![img](https://www.nowcoder.com/equation?tex=i%20%3D%202&preview=true) 开始有转移方程 ![img](https://www.nowcoder.com/equation?tex=f_%7Bik%7D%20%3D%20%5Cmax(f_%7Bik%7D%2C%20%5Cmax(f_%7Bi-1%2C%20w%7D%2C%20f_%7Bi-1%2C%20w%20%5Coplus%201%7D%20-%20k%5Bk%20%5Cleq%20f_%7Bi-1%2C%20w%20%5Coplus%201%7D%5D)%20%2B%20world_%7Bw%2C%20i%7D))

~~~C++
ll a[N], b[N];
const ll inf = 1e18;
void solve(){
    int n, k; cin >> n >> k;
    for(int i = 1; i <= n; i++)cin >> a[i];
    for(int i = 1; i <= n; i++)cin >> b[i];
    vector<vector<ll>>f(n + 1, vector<ll> (2, -inf));
    f[0][0] = f[0][1] = 0; 
    f[1][0] = a[1];
    for(int i = 2; i <= n; i++){
    	f[i][0] = max(f[i-1][0] + a[i], (f[i-1][1] >= k ? f[i-1][1] - k + a[i] : -inf));
    	f[i][1] = max(f[i-1][1] + b[i], (f[i-1][0] >= k ? f[i-1][0] - k + b[i] : -inf));
	}
    cout << max(f[n][1], f[n][0]) << "\n";
}
~~~







## [B2](https://ac.nowcoder.com/acm/contest/51727/B)

## 题目描述                    

你有一个长度为$n$的字符串，其中仅含'0','1','2'三个字符。

你希望知道，这个字符串有多少个子串，满足该子串的'0','1','2'个数相等？

​	

## 输入描述:

第一行一个正整数，代表数据组数$t(1\le t \le 10^4)$。
对于每组数据，第一行一个正整数$n(1\le n \le 3\cdot 10^5)$，接下来一行一个长度为$n$的仅含'0','1','2'的字符串。
保证所有的$n$之和不超过$3\cdot 10^5$。



## 输出描述:

对于每组数据，一行一个正整数表示答案。

---



这道题目有很多写法，但本质都是一样的

这道题目我们无从下手，我们不妨考虑这个字符串只有两个字符$0,1$ 这时候我们怎么考虑

我们直接令 $0$ 为 $-1$ ， $1$ 为$1$ 就行，然后做一个前缀和，记前缀和数组为$pre$ 

这个时候如果区间 $l, r$ 里面的$0, 1$数量相等那么和一段的和就是 $0$，即$pre_r - pre_{l-1} = 0$ 

接下来我们考虑怎么统计答案，像这种统计区间的问题，我们一般固定右端点去更新答案

我们固定右端点 $r$ 考虑以 $r$ 为 右端点的合法区间有多少，也就是有多少个$pre_{l-1} = pre_r$

注意到$l \leq r$ ，那么 $l - 1 < r$ , 我们要找的就是  $r$ 左边有多少个 $i$ 满足 $pre_{i} = pre_r$

我们用$map$统计

~~~C++
void solve() {
    int n; cin >> n;
    vector<int>a(n + 5, 0), pre(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] == 0) a[i] = -1;
        pre[i] = pre[i - 1] + a[i];
    }
    map<int, int>mp;
    int ans = 0;
    mp[0] = 1;
    for (int i = 1; i <= n; i++) {
        ans += mp[pre[i]];
        mp[pre[i]]++;
    }
    cout << ans << '\n';
}
~~~



那么这道题目要怎么写呢，我们受到上面的启发，我们让 $0$ 变成$-1$  $1$变成 $-2$  $2$变成 $3$ 

但是我们会发现这样$3$个$0$  和 一个$2$ 会被错误的统计，我们发现有两个负数时无法平衡

我们令$0$ 变成$-x$ ， $1$变成 $-x - 1$，   $2$ 变成 $2 * x + 1$  (x > 0)

如果$n$ 个 $0$ 和$m$ 个$2$ 相加会是 $0$ 那么有$n * x = 2 * m * x + m$

那么 只要有 $2 * x + 1$ 个 $2$  ，$x$ 个 $0$ 就可以了

注意到$n(1\le n \le 3\cdot 10^5)$，那么我们令 $x = 10^5$  就刚好卡住这个范围

~~~C++
void solve() {
    int n;
    string s;
    cin >> n >> s;
    map<int, int>mp;
    int ans = 0, sum = 0;
    int x = (int)1e5;
    mp[0]++;
    for (int c : s) {
        if (c == '0') sum += -x;
        else if (c == '1') sum += -x - 1;
        else sum += 2 * x + 1;
        ans += mp[sum];
        mp[sum]++;
    }
    cout << ans << '\n';

}
~~~



我们还可以用向量去统计答案，令$2$ 变成 (1, 1) ， $1$ 变成（-1,0）， $0$ 变成（0, -1）

这样我们完全不用担心上面的问题

~~~C++
using arr2 = array<int, 2>;

void solve() {
    int n;
    string s;
    cin >> n >> s;
    map<arr2, int>mp;
    int ans = 0;
    mp[{0, 0}] = 1;
    int x = 0, y = 0;
    for (int c : s) {
        if (c == '0') y--;
        else if (c == '1') x--;
        else x++, y++;
        ans += mp[{x, y}];
        mp[{x, y}]++;
    }
    cout << ans << '\n';

}
~~~

## [C](https://ac.nowcoder.com/acm/contest/24213/1005)

## 题目描述                    

  小q和他的老婆小z最近开了一家花店，他们准备把店里最好看的花都摆在橱窗里。 

  但是他们有很多花瓶，每个花瓶都具有各自的特点，因此，当各个花瓶中放入不同的花束时，会产生不同的美学效果。 

  为了使橱窗里的花摆放的最合适，他们得想个办法安排每种花的摆放位置。 

  可是因为小q和小z每天都太忙，没有时间设计橱窗里花的摆法，所以他们想让你帮他们求出花摆放的最大美观程度和每种花所放的位置。 

  每种花都有一个标识，假设杜鹃花的标识数为1，秋海棠的标识数为2，康乃馨的标识数为3，所有的花束在放入花瓶时必须保持其标识数的顺序，即： 

  杜鹃花必须放在秋海棠左边的花瓶中，秋海棠必须放在康乃馨左边的花瓶中。 

  如果花瓶的数目大于花束的数目。则多余的花瓶必须空置，且每个花瓶中只能放一束花。 

  每种花放在不同的瓶子里会产生不同的美观程度，美观程度可能是正数也可能是负数。 

  上述例子中，花瓶与花束的不同搭配所具有的美观程度，如下表所示： 

```
花    瓶
                  1     2    3    4    5
   1 (杜鹃花)     7    23   -5  -24   16
   2 (秋海棠)     5    21   -4   10   23
   3 (康乃馨)    -21    5   -4  -20   20
```

  根据上表，杜鹃花放在花瓶2中，会显得非常好看；但若放在花瓶4中则显得十分难看。 

  为取得最大美观程度，你必须在保持花束顺序的前提下，使花束的摆放取得最大的美学值，并求出每种花应该摆放的花瓶的编号。 

## 输入描述:

第1行：两个整数F和V，表示共有F种花，V个花瓶。
第2行到第F+1行：每行有V个数，表示花摆放在不同花瓶里的美观程度值value。(美观程度和小于$2^{31}$，美观程度有正有负)

## 输出描述:

输出有两行：第一行为输出最大美观程度和的值，第二行有F个数表示每朵花应该摆放的花瓶的编号。
若有多种方案，输出字典序较小的方案（美观程度不变的情况下，花尽量往前放）。

---

题目考点：二维线性DP （初学者可以参考代码对样例模拟状态转移的过程，有助于今后理解状态转移）

题目大意：n种花m个花瓶，花瓶顺序以及插入花的顺序固定，每种花在每个花瓶中美观度不同（有负数），问讲n种花插在哪n个花瓶里美观度最大。

题目分析：对于第i种花，它能获得的最大美观度为：在合法区间内，上一种花所在位置后面的花瓶中的最大美观度的位置（其中合法区间是指从上一种花(上一种花用k维护)放的位置开始，到使得i后面的话有花瓶可以放的区间，比如根据题目样例，对于第2种花来说，它最后能放的位置为4，后面至少留1个花瓶的位置）。
因此转移方程：dp [ i ][ j ] = max (dp [ i ][ j ],  dp [ i-1 ][ k ] + v [ i ][ j ]);
代码：

```c++
#include<iostream>
#include<algorithm>
#include<cstring>
using namespace std;
const int N = 105, INF = 0x3f3f3f3f;
int dp[N][N], v[N][N], id[N];
int n, m;
int main()
{
  scanf("%d%d", &n, &m);

  for(int i = 1; i <= n; i++)
  for(int j = 1; j <= m; j++)    //dp数组初始化极小值
      scanf("%d", &v[i][j]) , dp[i][j] = -INF;

  for(int i = 1; i <= n; i++)
  for(int j = i; j <= m - (n-i); j++) //第i种花的合法区间(合法区间的定义写在上面了)
  for(int k = i-1; k < j; k++)        //k维护上一层的摆放情况
      dp[i][j] = max(dp[i][j], dp[i-1][k] + v[i][j]);

  //寻找最大美观度
  int ans = -INF;
  for(int i = 1; i <= m; i++)
      ans = max(ans, dp[n][i]);
  printf("%d\n", ans);

  //寻找位置  
  int pos = n;
  for(int i = n; i ; i--)  //倒推寻找位置
  for(int j = 1; j <= m; j++)  //对于每一种花，遍历所在层寻找
      if(dp[i][j] == ans) //ans对应dp维护的值，证明找到了位置
      {
          id[pos--] = j;   
          ans -= v[i][j];
          break;   //该层位置找到后记得直接跳到再上一层寻找上一层的位置
      }
  for(int i = 1; i <= n; i++)  //输出n种花的位置
      printf("%d ", id[i]);
  return 0;
}
```

随后，他会独立地反转每一个子段 $[a_{l_i}, a_{l_i+1}, \dots, a_{r_i}]$。经过此操作后，原数组将变为 $[a_{r_1}, a_{r_1-1}, \dots, a_{l_1}, a_{r_2}, \dots, a_{l_{k-1}}, a_{r_k}, a_{r_k-1}, \dots, a_{l_k}]$。

每个测试用例的第二行包含 $n$ 个整数 $T_1, T_2, \dots, T_n$ ($1 \le T_i \le 8000$)，表示数组 $T$ 中的元素。

保证所有测试用例中 $n$ 的总和不超过 $8000$（即 $\sum n \le 8000$）。

#### 输出格式

对于每个测试用例，输出一个单行整数，表示满足条件的数组 $S$ 的数量对 $998244353$ 取模后的结果。
