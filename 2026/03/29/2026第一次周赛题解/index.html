B档题

B1

tags

  • 2088D
  • 难度1100
  • 经典置换环
  • 并查集典型应用

题目大意

  • 给定一个长度为 $n$ 的排列 $p$，满足包含 $1 \sim n$ 且不重复

  • 从某个位置 $i$ 出发，可以不断执行 $ i \leftarrow p_i $

  • 若从 $i$ 出发，经过若干次操作可以到达 $j$， 则称 $j$ 对 $i$ 可达

  • 给定一个字符串 $s$：

    • $s_i = 0$：表示 $p_i$ 是黑色
    • $s_i = 1$：表示 $p_i$ 是白色

  • 定义：$ F(i) = \text{从 } i \text{ 出发能到达的所有点中，黑色点的数量} $

  • 输出所有 $F(1), F(2), \dots, F(n)$

解题思路

  • 不难发现从任意位置出发，一定能回到该位置
  • 整个数组会依据可达的性质被分组，形成一个环
  • 环内任意元素一定可达，环与环之间任意元素不可达
  • 每个数字 $x$ 对应的 $F(x)$ 是他所在环内黑色点数量
  • 用并查集维护每个数字所在的环即可

B2

tags

  • 1617C
  • 难度1300
  • 贪心、排序

题目大意

  • 给定一个n，以及一个长度为n的数组 $a$。
  • 每次操作，选择其中一个数字 $a_i$，以及任取一个正整数 $x$，让 $a_i = a_i \mod x$
  • 问能不能将数组通过若干次操作后变成1 ~ n的一个排列
  • 如果不能，输出-1，能的话输出最少操作次数。

解题思路

  • 注意到，一个数模另一个小于它的数，肯定会变小
  • 同时，如果要将一个较大的数模 $x$ 得到 $k$ ，那么这个数必须大于 $2\times k + 1$
  • 首先为了最优性，那些刚好能填补1 ~ n 的位置的数，先填补上，这部分不变
  • 接下来从小到大查找空缺的位置，如果存在空缺 k，那么就取当前没有被用过的最小数字 $y$ 去操作
  • 如果满足 $y > 2\times k + 1$ ，那么答案加一
  • 否则说明当前数 $y$ 无论操作与否，都不能参与构成最后的结果，反过来说就是排列无法构造，输出 $-1$ 即可

C档题

tags

  • 1976C
  • 难度1600
  • 模拟、分类讨论

解题思路

这题的难点是情况很多，少考虑一种就会出错

  • 首先我们来看所有人都来了是什么情况

  • 我们定义一个人最后去了程序员就是A类人，否则就是B类人

  • 我们从左到右遍历，如果a[i] > b[i] 并且 A类人没有满，那这个人就可以去A类，我们把他们叫作主动去A的人。如果A满了就只能去B，我们叫做被迫去B类

  • 如果a[i] < b[i] 并且 B类人没有满，那这个人就可以去B类，我们把他们叫作主动去B的人。如果B满了就只能去A，我们叫做被迫去A类

  • 这里很简单，我们计数就可以了。

  • 然后我们会发现前n + m个人就会把岗位全部占满，这时候最后一个人只能来补位了（如果没有人不来，那这个人就没有工作了qwq）

  • 那么我们开始考虑第 $i$ 个人没来会出现什么情况

    • 如果这个人是主动去A的人，那么这时候就会多出一个A类人的空位置，那么我们找到第一个被迫去B的人，让他去A就行了，然后让最后一个人补到B去。如果没有被迫去B的人，那我们让最后一个人去A就行了

    • 如果这个人是被迫去的A，那么说明这个时候B已经满了，那我们让最后一个人去A就行

    • 其它两种也是一样的

D档题

tags

  • 2173D

  • 难度 1900，dfs、数位dp

题目大意

  • 给定一个正整数 $n$ 和一个正整数 $k$，需要进行 恰好 $k$ 次操作。

  • 每次操作中，可以任选一个非负整数 $\ell$，并将当前的 $n$ 更新为 $n ：= n + 2^\ell$

  • 一次操作的得分，定义为：在 二进制下 计算 $n + 2^\ell$ 时，产生的 进位次数。

  • 总得分是 所有 $k$ 次操作得分之和。

  • 目标是：通过合理选择每一步的 $\ell$，使得在完成 $k$ 次操作后，总得分最大化

解题思路

  • 数位dp，从低到高遍历该数二进制的 **每一块连续的 $1$ **，考虑是否对其操作

  • 操作过程中维护两个变量： 当前数字和剩余操作次数

  • 设 $f(n, k)$ 表示其最大总分，考虑当前 最靠后的连续1的块 有:

    • 如果对当前对这个块操作 :

      $num1=f(n + lowbit(n), k-1) + popcount((n + lowbit(n))\oplus n) - 1$

    • 如果不对其操作：

      $num2=(n + lowbit(n)) \oplus lowbit(n + lowbit(n))$

  • 取二者最大值：$f(n,k) = max(num1, num2)$

  • 直接 $dfs$ 即可。 $k=0$ 时表示操作结束返回 $0$，$lowbit(n) = n$ 时直接返回 $k$.

  • 时间复杂度 $O(k \cdot logn)$
