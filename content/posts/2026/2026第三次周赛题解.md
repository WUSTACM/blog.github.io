# B

链接：https://codeforces.com/problemset/problem/1984/B

## 题意

这个也不解释。

## 思路

要构成5~9的数，同时位数相同，必须向下一位留1，也就是说加上上一位留下的1之后在11到19之间，再留1刚好满足。

即首位不为大于1的数，否则留多了，中间有0则无法留1，最后有9无法平分。

## 代码

```cpp
void solve() {
    string s;
    cin >> s;
    if(s[0] != '1' || s[s.length() - 1] == '9') return (void)(cout << "NO" << "\n");
    for(int i = 0; i < s.length() - 1; i++) {
        if(s[i] == '0') return (void)(cout << "NO" << "\n");
    }
    cout << "YES" << "\n";
}
```

# C

## 题意

题目的K个为不连续取，看错题目回去重修语文。

## 思路

有个小贪心，对于要满足的条件，如果$a_{i-1}>a_i$，只需要让$a_i$加上$a_{i-1}-a_i$的值就能让$a_{i-1}=a_i$

假设每次操作只消耗k个硬币，所以将当前的数与前缀最大值做差，与0做比较，即为消耗k硬币的贡献。

每次操作额外消耗1硬币，找到差值最大的数就是额外消耗的硬币数量。

## 代码

```cpp
void solve()
{
    int n;
    cin >> n;
    vector<ll> a(n + 1, 0);
    for(int i = 1;i<=n;i++){
        cin >> a[i];
    }
    ll maxn = 0, maxdiff = 0, ans = 0;
    for (int i = 1;i<=n;i++){
        ans += max(maxn - a[i], 0ll);
        maxdiff = max(maxn - a[i], maxdiff);
        maxn = max(maxn, a[i]);
    }
    cout << ans + maxdiff << endl;
}
```

# D

链接：https://ac.nowcoder.com/acm/problem/14675

## 题意

取两堆糖果，相加 mod P 之后的最大值。

## 思路

可以先 mod P ，然后剩下的一些数排序去重，先取一个 x（通过遍历）， 再二分查找 p-x 的位置（lower_bound为二分查找大于等于它的第一个），那么前面一个就是相加不超过p的最大值，可能超过p的最大值则直接加上最后一个 mod p 就行。

## 代码

```cpp
void solve() {
    ll n, p;
    cin >> n >> p;
    vector<ll> a(n,0);
    for(ll i = 0; i < n; i++) {
        cin >> a[i];
        a[i] %= p;
    }
    sort(a.begin(), a.end());
    unique(a.begin(),a.end());
    ll ans = 0;
    for(ll i = 0; i < a.size(); i++) {
        ll t = p - a[i];
        ll tt = lower_bound(a.begin(),a.end(),t) - a.begin();
        tt--;
        if(tt == i) tt--;
        if(tt > 0) ans = max(a[i] + a[tt], ans);
        if(i != a.size()-1) ans = max(ans, (a[i]+a[a.size()-1])%p);
    }
    cout << ans << endl;
}
```

# E

链接：https://codeforces.com/problemset/problem/1927/D

这题赛时数据水了，可以到原题目链接去重新提交。

## 题意

不解释。

## 思路

将数字连续的区间分成不同的组，如果$l,r$在同一组，则这个区间内所有的数都相同。

当$l,r$不同时，相邻两个区间内的一定不同，故用双指针~~(也可以不用)~~将每个区间的左右边界存入数组中，最好想的想法是以找到$l$所在区间的下一个区间，其第一个数一定与$l$不同。

## 代码

```cpp
void solve()
{
	int n;
	cin >> n;
	vector<int> a(n + 1, 0);
	for (int i = 1; i <= n;i++){
		cin >> a[i];
	}

	vector<pair<int, int>> vp;
	for (int l = 1, r = 1; r <= n;r++){
		if(a[r]==a[r+1])
			continue;
		vp.push_back({l, r});
		l = r + 1;
	}
	vp.push_back({n + 1, n + 1});

	int q;
	cin >> q;
	vector<array<int, 3>> qu(q); // 离线处理，可以用在线二分替换
	int cnt = 1;
	for(auto &p : qu){
		cin >> p[0] >> p[1];
		p[2] = cnt++;
	}

	sort(qu.begin(), qu.end());
	vector<pair<int,int>> ans(q + 1, {-1,-1});
	int p = 0;
	for (auto [l,r,i] : qu){
		while(vp[p].second<l)
			p++;
		auto [x, y] = vp[p];
		if(r>y)
			ans[i] = {l, y + 1};
	}
	for (int i = 1; i <= q;i++){
		cout << ans[i].first << ' ' << ans[i].second << endl;
	}
}
```

# F

链接：https://codeforces.com/problemset/problem/1849/D

## 题意

单一蓝转红花1费，通过有数字的红转附近不花费，同时红色数字减1。

## 思路

先将1和2转成红色，再用1和2将附近转变最好。而将连续的非0设置成一块，里面有2则可以将块两边都染色，没2随便染一边，用指针记录，vis记录颜色。最后遍历一遍扫0。

## 代码

```cpp
void solve() {
    int n;
    cin >> n;
    int ans = 0;
    vector<int> a(n+1,0), vis(n+1,0);
    for(int i = 1; i <= n; i++) cin >> a[i];
    for(int i = 1; i <= n; i++) {
        if(vis[i] == 0 && a[i] != 0) {
            int flag = 0;
            ans++;
            int l = i, r = i;
            while(r <= n & a[r] != 0) {
                if(a[r] == 2) flag = 1;
                vis[r] = 1;
                r++;
            }
            r--;
            if(flag == 0) {
                if(l > 1 && vis[l-1] == 0) vis[l - 1] = 1;
                else if(r < n && vis[r+1] == 0) vis[r + 1] = 1;
            }
            else {
                if(l > 1 && vis[l-1] == 0) vis[l - 1] = 1;
                if(r < n && vis[r+1] == 0) vis[r + 1] = 1;
            }
            i = r;
        }
    }
    for(int i = 1; i <= n; i++) {
        if(vis[i] == 0) ans++;
    }
    cout << ans << endl;
}
```

# G

链接：https://ac.nowcoder.com/acm/contest/11198/B


## 题意

构造两个数组a和b，每个数字在$0$到$2^m$内，问a数组按位或大于b数组按位异或有多少种构造方法

## 思路

a,b数组位运算后的结果一定在$0$到$2^m$内，遍历结果二进制的每一位，a的结果大于b时一定是在某一位二进制位a是1，b是0。假设决定a大于b的是第i位，i位前每一位a的结果一定和b的结果相同,i位后每一位都可以随机。考虑如何构造，i位前a数组的所有数字都可以乱填，而b数组只用留一个数字，其他数字乱填即可以使a，b相同，在第i位上，a数组只需要在那一位上有一个1即可，其余可以乱填，而b数组仍然只需要留一个数字就可以把那一位变成0。最后注意要考虑a，b结果相同的情况

## 代码

``` cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

const int mod = 1e9 + 7;

int ksm(int a, int b) {
    int res = 1;
    while (b > 0) {
        if (b & 1) res = (res * a) % mod;
        a = (a * a) % mod;
        b >>= 1;
    }
    return res;
}

void solve() {
    int n, m;
    cin >> n >> m;
    int ans = 0;
    for(int i = 1; i <= m; i++) {
        ans = (ans + (ksm(ksm(2, 2 * n - 1), m - i) * (ksm(2, n) - 1) % mod * ksm(2, n - 1) % mod ) % mod * (ksm(ksm(2, 2 * n), i - 1)) % mod) % mod;
    }
    ans = (ans + ksm(ksm(2 , 2 * n - 1), m)) % mod;
    cout << ans << endl;
}

signed main() {
    int _ = 1; 
    // cin >> _;
    while(_--) {
        solve();
    }


}

```
